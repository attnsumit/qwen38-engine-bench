Verdict

Accuracy is the same on these tests. For throughput and time-to-first-token under load, TensorFold was ahead on this box. At a single stream, the two were tied.
Scope: one GB10, one checkpoint family (NVIDIA NVFP4 QAD; Flare runs its compiled build of the same weights), text only, thinking off. GSM8K first 100 questions; HumanEval first 20 tasks; n is small, so accuracy gaps under ~10 points are within noise. Speed: 3 repeats, median; nonce prefix per request, so prompt caches cannot flatter TTFT. Page cache not flushed (no sudo). Engines were run one at a time on port 8888. Full methods and raw outputs are in the results folder.
